## MM-001 | Login error message persists after valid input

**Severity:** Medium
**Priority:** Medium
**Status:** Closed — Fixed

**Summary:** After a failed login attempt, the error message banner remains visible even after the user clears the fields and types valid credentials. The error only disappears on form submission.

**Steps to Reproduce:**
1. Navigate to https://www.saucedemo.com
2. Enter an incorrect username and password
3. Click Login — error message appears
4. Clear both fields
5. Enter valid credentials without submitting

**Expected Result:** Error message clears as soon as the user starts editing the fields.
**Actual Result:** Error message remains visible until the form is re-submitted.

**Root Cause:** Missing `oninput` event listener to clear error state on field change.
